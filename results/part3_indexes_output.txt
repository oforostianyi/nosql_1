========================================================
Завдання 3. Чи є запит покривним (covered query)?
========================================================
Варіант А: як в умові, без переліку полів (база повертає весь запис):
>>> ЗАПИТ: db.tracks.find(
{
  track_genre: 'pop',
  popularity: {
    '$gte': 70
  }
}

)
{
  label: 'завдання 3: без проєкції',
  stages: 'FETCH → IXSCAN',
  executionTimeMillis: 0,
  totalKeysExamined: 317,
  totalDocsExamined: 317,
  nReturned: 317
}

Варіант Б: повертаємо лише поля з індексу і не повертаємо _id:
>>> ЗАПИТ: db.tracks.find(
{
  track_genre: 'pop',
  popularity: {
    '$gte': 70
  }
}
, 
{
  _id: 0,
  track_genre: 1,
  popularity: 1
}
)
{
  label: 'завдання 3: покривна проєкція',
  stages: 'PROJECTION_COVERED → IXSCAN',
  executionTimeMillis: 0,
  totalKeysExamined: 317,
  totalDocsExamined: 0,
  nReturned: 317
}

Висновок: варіант А не покривний (є стадія FETCH, прочитано записів: 317).
Варіант Б покривний (стадія PROJECTION_COVERED, прочитано записів: 0).
